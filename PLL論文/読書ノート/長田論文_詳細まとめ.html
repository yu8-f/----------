一言でいうと

「Fractional-N PLL の宿敵である DSM量子化ノイズ と フラクショナルスパー を、フィードバック経路の分周器（÷N）を 高調波ミキサ（HM）による周波数の引き算に置き換えることで、キャリブレーション無しで抑え込む。その具体的な回路として Dual-Feedback アーキテクチャ を提案し、さらに3つの弱点（ノイズシェーピング周波数の頭打ち／HM固有のオフセットスパー／余分なVCOのオーバーヘッド）を潰す派生構成を順に示した論文。」

なぜ分周器がダメなのか（この論文の出発点）

  • PLL は負帰還系。ループ利得が十分大きい帯域では、入力換算ノイズは「フィードバック利得の逆数 1/β」倍されて出力に出る。
  • 分周比 N の分周器を帰還に使うと β = 1/N なので、入力側のノイズ（＝DSM量子化ノイズも）が N 倍される。例：100MHz基準から2.4GHzを作ると 20 log(24) ≈ 27.6 dB も増幅。
  • 対策：帰還を「割り算」ではなく「引き算」にする。ミキサで $f_\text{OUT}-f_\text{LO}$ を作れば、位相ドメインの帰還利得は β = 1（ユニティ）。ノイズは増幅されない。
  • ただし単純ミキサだと $f_\text{OUT}\approx f_\text{LO}$ になり 周波数引き込み（frequency pulling） が起きる → 高調波ミキサ HM で $f_\text{HM}=f_\text{OUT}-k\,f_\text{LO}$（k は高調波次数）にして距離を取る。

PN（位相雑音）ではなくジッタで考える理由

出力を ÷N すると PN は 1/N（パワーで 1/N²）に減るが、周期も N 倍になる。位相は「1周期＝2π」で定義される相対量なので、両者が打ち消し合い 積分ジッタ（時間軸の揺らぎの標準偏差）は不変。だから「PNが下がった」だけでは意味がなく、$\sigma \propto \sqrt{\text{積分PN}}\,/\,f_\text{OUT}$ で決まる積分ジッタを指標にする。「ノイズ増幅の回避」も、この積分ジッタ基準で効いてくる話。

第1章 — Introduction（なぜ周波数シンセサイザが重要か）

1.1 周波数シンセサイザの用途と、性能が効くメカニズム

周波数シンセサイザ（＝安定な周波数源。多くはPLLで実現）は無線・有線通信やレーダの根幹部品で、シンセの性能がそのままシステム性能を律速する。3つの代表例で「どの性能指標が、なぜ効くか」を押さえる。

① 有線リンク（serial link / SerDes）— ジッタが BER を悪化させる

  • TX側PLLがデータ送出タイミングのクロックを作る。チャネル通過 → イコライザで損失補償 → RX側の CDR（Clock and Data Recovery）が生成したクロックで再サンプリングして 0/1 判定。
  • 判定が最も確実なのは「RXクロックのエッジが、TXの隣り合う遷移のちょうど中間」に来るとき。ズレると閾値近くでサンプルしてしまい BER（ビット誤り率）が増える。
  • DCスキューや低周波ノイズは CDR が受信データ基準でRXクロックを作るので抑えられるが、CDR帯域外の高周波ノイズ（TX PLL・チャネル・CDR自身）は残る。低BER・高チャネル損失・低電力・低面積を同時に満たしつつ低ジッタなクロックを安く作るのが課題。マルチチャネル化（レーンごとにクロック）も進むので 小面積 も重要。

② 無線受信機 — 位相雑音が reciprocal mixing と EVM を悪化させる

  • 受信信号を LO とミキシングしてダウンコンバート。LO の位相誤差 → コンスタレーションが回転 → シンボル位置がずれて BER 増。ノイズによるずれ／シンボル間距離の比が EVM（Error Vector Magnitude）。高次変調ほどシンボルが密集して EVM 要求が厳しい。
  • Reciprocal mixing：受信帯には希望波のほかに離れた周波数に大きな妨害波（blocker）がある。理想LOなら妨害波はダウンコンバート後もオフセットを保ちLPFで除去できるが、実際のLOは位相雑音の裾（skirt）を持つので、ダウンコンバートされた妨害波の裾が希望波に被さる。この裾は希望波と同じ周波数位置なのでもうフィルタで取り除けない。LOのスパーでも同じことが起こる。
  • 周波数ホッピングやIoTのデューティサイクル動作では 整定時間（settling time） も重要。

③ FMCWレーダ — 位相雑音が距離分解能を悪化させる

  • 周波数を鋸歯状に変調した chirp 信号を送信 → 物標で反射 → 往復時間だけ遅れて戻る。送受信をミキシングして得る ビート信号の周波数から距離を算出（傾き×往復時間、傾きは既知、速度は光速）。
  • chirp に含まれる位相雑音がビート信号の周りにノイズを作る。近い距離に複数物標があると、一方のビート信号のノイズが他方を汚染 → SNR低下 → 2物標を分離する分解能が落ちる。chirp の直線性も重要（崩れるとビート周波数が一定にならずスペクトルがにじむ）。

🧠 まとめ

用途は違っても「シンセの ジッタ・スパー・電力・帯域・面積・整定時間・chirp直線性 がシステムの限界を決める」構図は共通。だから性能改善の意味が大きい。

1.2 この論文のインパクト（HMベース PLL の立ち位置）

いまの高性能 Fractional-N PLL の多くは DTC（Digital-to-Time Converter） で量子化ノイズをキャンセルしてジッタ-電力性能を稼ぐ。この論文は別路線の HM（Harmonic-Mixer）ベース帰還 を追う。HMベースの利点：

観点DTCベースHMベース（この論文）
キャリブレーション必須。DTCのゲイン・線形性を LMS / LUT で補正。起動時だけでなく周波数切替のたびに必要。不要。線形なループそのもので抑圧するため。
ロック時間ループ過渡（数百ns〜数十µs）＋キャリブレーション収束（数十µs〜最悪ms）。ループ過渡のみ（数百ns〜µs）。
残留ノイズの予測非理想性・2次効果由来でモデル化困難。全回路シミュも時間スケールが違いすぎて厳しい。理想線形モデルで予測でき、非理想性は微小なずれとして乗るだけ。
ハードウェアLUT・複数アキュムレータで複雑。LUT不要。マルチチャネル（UCIe等）に向く。
リングVCO化—キャリブレーション不要と組み合わせて小面積・柔軟なクロック源（5章で実証）。
  • デューティサイクル無線（IoT）：TX/RXを短時間だけ点けて平均電力を下げる。PLL起動が遅いと点灯時間を延ばさざるを得ず省電力効果が頭打ち → キャリブレーション不要が効く。
  • チップレット（UCIe など）：プロセス別ブロックを上位層で接続。チャネルごとに個別PLLが欲しいが、キャリブレーション集約型はLUTが大きくて不向き。HMベースはLUT不要でリングVCO化もでき、コンパクト。
  • 解の多様性：既存解（DTC）があっても別アプローチを持つ価値。ADC分野でリングアンプが「アンプベースADCを生き残らせ、後にノイズシェーピングSAR等の新構成を生んだ」のと同じ論法。

💬 第1章 Q&A

1「PNが希望波と同じ位置に来るともう除去できない」ってどういうこと？

妨害波をLOでダウンコンバートすると、LOの位相雑音の裾が妨害波にコピーされる（4.2.2の「スペクトル＝PNを搬送波の両側にコピー」の関係）。その裾が、ダウンコンバート後の希望波（DC付近）と周波数軸で重なると、フィルタは希望波ごと削ってしまうので分離不能。これが reciprocal mixing。

2DTCベースが強いのに、なぜHMベースをやるの？

DTCは性能は良いがキャリブレーションが要る。周波数切替のたびに数十µs〜msの収束待ちが入るので、頻繁に周波数を変えるシステムやデューティサイクル無線では致命的。HMベースは線形ループそのもので抑圧するのでキャリブレーション不要＝ロック時間はループ過渡だけ。ジッタ-電力性能もDTCベースに肉薄（3.5節・条件次第で同等以上）。

3「解の多様性」って精神論では？

実利の話。プロセスや周辺回路の進歩で、いま2番手の方式が将来1番手になることがある。リングアンプの例：微細化で低電源になりアンプが作りにくくなった時期にSAR ADC一辺倒になりかけたが、スケーリングに強いリングアンプを残したことで、後に「SARの発想＋アンプベースの発想」を融合したノイズシェーピングSAR ADCという新構成が生まれた。ツール箱に選択肢を維持すること自体が次のブレークスルーの種になる。

$H_\text{DIV,OUT}(s)$$-H_\text{LPF}(s)$LPF型、極性反転

各ノイズ源のPSDに $|H|^2$ を掛けて足すと出力PN。

簡略モデルと基本トレードオフ（Fig. 2.3〜2.5）

  • $v_\text{nLF}$ は無視。基準経路・分周器・PDのノイズは伝達関数がどれもLPF型（DC値だけ違う）で、みな白色近似できるので 1個の等価基準換算ノイズ $\phi_\text{nEQUIV}$ にまとめる：
    $\phi_\text{nEQUIV}=\phi_\text{nREF}-\phi_\text{nDIV}+\dfrac{1}{K_\text{PD}}i_\text{nPD}$,   $S_\text{nEQUIV}=S_\text{nREF}+S_\text{nDIV}+\dfrac{1}{K_\text{PD}^2}S_\text{nPD}$
  • 結局ノイズ源は2つ：入力側の $\phi_\text{nEQUIV}$（白色、LPF通過）と VCO の $\phi_\text{nVCO}$（$1/f^2$、HPF通過）。
  • 両者のカットオフが同じ $\omega_\text{UG}$ → $\omega_\text{UG}$ を下げると $\phi_\text{nEQUIV}$ は減るが $\phi_\text{nVCO}$ が増える。逆も然り。バランス点で合計ジッタ最小。

数値例（この論文が繰り返し使う設定）

$f_\text{REF}=100$ MHz、$f_\text{OUT}=2.4$ GHz、等価基準換算ノイズ床 −150 dBc/Hz、VCO −120 dBc/Hz @1MHz、$K_\text{PD}=100\mu\text{A}/2\pi$、$K_\text{VCO}=2\pi\cdot30\times10^6$。
→ integer-N の最適ジッタ ≈ 175 fs（$\omega_\text{UG}\approx1.5$ MHz）。帯域を 300kHz に狭めるとVCOノイズが支配、7.5MHzに広げると基準系が支配。

「合計ノイズ」の定量化＝積分ジッタ（ゼロ交差タイミング誤差の標準偏差）。PNスペクトルを適切な範囲で積分して位相誤差の分散 → タイミング誤差の標準偏差へ変換（Wiener–Khinchin）。この例の積分範囲は 10kHz〜1GHz。

2.1.2 安定条件

2次LFのとき

$$H_\text{OL}(s)=\frac{K_\text{PD}K_\text{VCO}}{N_1(C_1+C_2)}\cdot\frac{1+s/\omega_z}{s^2\,(1+s/\omega_p)}$$

  • DCに2極 → そのままでは位相 −180°で不安定。$\omega_z$ の零点で位相を持ち上げ、$\omega_\text{UG}$ で十分な位相マージンを確保。$\omega_\text{UG}$ は $\omega_z$ と $\omega_p$ の間に置く。
  • 定番設計：$\omega_p/\omega_\text{UG}=\omega_\text{UG}/\omega_z\equiv a$。このとき（$a\gg1$ 近似）
    $R\approx\dfrac{N_1\omega_\text{UG}}{K_\text{PD}K_\text{VCO}}$,   $C_1\approx\dfrac{a K_\text{PD}K_\text{VCO}}{N_1\omega_\text{UG}^2}$,   $C_2=\dfrac{K_\text{PD}K_\text{VCO}}{a N_1\omega_\text{UG}^2}$
  • $K_\text{PD}$, $K_\text{VCO}$ はノイズ・チューニングレンジで先に決まるので、$R$, $C_1$, $C_2$ で所望特性を作る。
  • 注意：PDは連続的に位相差を出すのではなく、入力の立ち上がりエッジでのみ動作＝サンプリング動作を含む。帯域が $f_\text{REF}$ に対して十分狭ければ無視できるが、広帯域設計では基準周波数付近のPN成分がエイリアスで折り返す（4章で別文脈で扱う）。

2.2 Fractional-N PLL の量子化ノイズとフラクショナルスパー

2.2.1 ΔΣ変調による小数分周

  • 分周器はエッジで駆動される（あるいはILFDは入力＝出力の高調波でしかロックしない）ので 整数分周しかできない。基準周波数を下げるのは帯域を大きく制限するので筋が悪い。
  • MMD（Multi-Modulus Divider）の分周比を時間変化させ、平均で目的の小数分周比を得る。例：÷2.25 を 2,3,2,2… で近似。位相誤差 $\Delta\phi$ は $-0.125T_\text{PLL},-0.375T_\text{PLL},0.375T_\text{PLL},0.125T_\text{PLL}$ を巡回し平均ゼロ。
  • 平均はゼロでも $\Delta\phi$ が常に変動 → 帰還信号に乗る雑音＝量子化ノイズ（分周器出力のエッジが入力エッジに揃わされるため）。周期的パターンだと巨大スパー（÷2.25の例なら周期 $9T_\text{PLL}$＝$0.25f_\text{REF}$）→ 使い物にならない。
  • 白色化 → 白色量子化ノイズ。さらに ノイズシェーピング（高域へ押し出す）すると、PLLのLPF特性でより多く除去できる。これを実現するのが ΔΣ変調器（DSM）：小数部を入力、平均が入力に等しい整数列を出力、量子化ノイズは整形される。
  • MASH 1-1-1：1次DSMを3段。1・2段目の量子化ノイズはキャンセルされ、3段目 $Q_{n3}$ に $(1-z^{-1})^3$（3次離散時間HPF）が掛かる＝3次ノイズシェーピング。安定。$Q_{n3}$ は白色近似（必要ならディザ追加）。

⚠ ノイズシェーピングしても足りない

同じ条件で $N=24.01$ にすると、fractional-N の最適ジッタ ≈ 290 fs（$\omega_\text{UG}\approx300$ kHz）。integer-N の 175 fs より大幅に悪い。DSM量子化ノイズを抑えるには帯域をかなり狭める必要があり、そのぶんVCOノイズが増える。これが Fractional-N の宿痾で、この論文全体の敵。

2.2.2 フラクショナルスパーの発生

  • ① DSMのランダム化は完全でなく、出力にわずかな周期性が残る（ディザで低減できるがPNは少し悪化）。
  • ② 量子化ノイズがループ内の非線形性（CPの電流ミスマッチ、SPDのスロープ非線形）に入ると ノイズフォールディングで低周波スパー化。PDの非線形性はLFでまだ量子化ノイズが抑えられていない位置なので特に厄介。
  • スパーは $\alpha f_\text{DSM}$（＝$\alpha f_\text{REF}$）とその高調波に出る。微細分解能が要る用途では $\alpha$ が非常に小さくなる → スパーがごく低いオフセット（near-integer fractional spur）に出て、帯域を狭めても除去できない。

2.2.3 先行手法（3系統）

系統① ノイズキャンセル（IDAC / DTC）
  • MMD制御列と目標小数分周比の差を積算 → 期待される位相誤差を予測してキャンセル。IDAC は CP 出力で電流を引く [37–39]。DTC は基準経路（またはMMD後の帰還経路）で時間をずらす [40–45]。
  • DTC が近年主流：PD に入る前にキャンセルできるので、PD は狭い範囲でだけ線形／高精度ならよい。SPD は入力が大きいと被サンプル信号の非線形性で悪化、TDC は広範囲＋高分解能を両立すると大電力。
  • 難点：キャンセル信号と実信号のマッチング。ゲイン誤差は LMS、線形性は LUT による区分的プリディストーションで補正 → キャリブレーション必須。収束は数十µs〜最悪ms。残留ノイズ・スパーはモデル化困難。ハード複雑（LUT・複数アキュムレータ）。定スロープDTC [46] は線形性キャリブレーションを緩和できるがジッタ/電力効率が落ちる。
系統② ノイズシェーピング周波数を上げる
  • DSMを高速クロックで回すと量子化ノイズが高域へ → 狭帯域でも十分除去できる。基本PLLでは $f_\text{DSM}=f_\text{REF}$ なので高い $f_\text{REF}$ が要る。数値例：$f_\text{REF}$ を 100→600 MHz にすると 1.5MHz帯域のままでもジッタ ≈ 189 fs（integer-N の 175fs に肉薄）。
  • 高周波水晶は高価（数十MHz級が普通、数百MHzはほぼ入手不可）。→ カスケードPLL [47] / 基準逓倍器（ダブラ [48]、まれにクアドラプラ [49,50]）、split分周器＋中間周波数でDSMクロック [51]、MEMS発振器 [52,53]。
  • [51]の落とし穴：単純に分周器を2分割して中間点でDSMを叩くと、2段目分周器がエッジセレクタとして働き量子化ノイズがエイリアスで帯域内に戻り台無し。→ 2段目に M 位相出力を持たせ全エッジを保存、M個のXOR PDで1つの基準と比較（XOR PDは入力オフセット可）。難点：全XOR PDが線形域である必要で M に上限、大きな基準スパー。DSMロジックは 65nm で数百MHz以上だと誤動作／大電力。
系統③ 等価FIRフィルタで追加のフィルタリング
  • 主ループの特性を変えずにフィルタを追加するのがミソ（変えたら狭帯域PLLと同じでVCOノイズに不利）。
  • 同じPLL出力成分＋遅延の違う量子化ノイズを含む複数の帰還信号を作り、重み付き加算 → 量子化ノイズだけ等価FIRで整形、PLL出力成分は無加工。
  • 実装：複数MMD＋対応PFD/CP（DSM出力を基準周期の倍数だけ遅延、CP電流で重み付け）[55,56]。または MMD出力を基準周期の遅延線に通し XOR PD＋抵抗加算 [57,58]（XOR＋抵抗加算はPFD/CPより線形）。難点：経路間のゲイン・線形性のマッチング、遅延線の複雑さ・電力。

どれも一長一短。改善量とオーバーヘッドは条件で大きく変わる。HMベース帰還（3章）はこれらと直交する「新しいつまみ」＝ノイズ伝達関数のDCゲインを下げる、なので他手法と組み合わせられる（5・7章）。

2.3 章のまとめ

PLL設計の基礎（線形モデル・伝達関数・安定条件）、基本トレードオフ（$\omega_\text{UG}$：基準系 vs VCO）、Fractional-N 固有の量子化ノイズ／スパー、その先行対策3系統を整理した。

✅ 第2章 理解度確認問題

Q2-1. VCOノイズが「HPF型」で出力に出る理由を、$H_\text{OL}(s)$ の大小で説明せよ。

$H_\text{VCO,OUT}=1/(1+H_\text{OL})$。低域では $|H_\text{OL}|\gg1$（DCに2極なので発散）→ $H_\text{VCO,OUT}\approx1/H_\text{OL}\propto s^2$ で小さい。$\omega_\text{UG}$ 以上で $|H_\text{OL}|\ll1$ → $H_\text{VCO,OUT}\approx1$。よって低域を抑え高域を通すHPF、カットオフ $\omega_\text{UG}$、ロールオフ 40 dB/dec。

Q2-2. 基準系ノイズとVCOノイズの帯域トレードオフを1文で。最適帯域はどこ？

基準系ノイズ（白色）はLPFで、VCOノイズ（$1/f^2$）はHPFで出力に出て、両者のカットオフが同じ $\omega_\text{UG}$ なので、$\omega_\text{UG}$ を下げると基準系は減るがVCOが増え、上げると逆になる。最適帯域は両寄与がバランスし積分ジッタが最小になる点（例では ≈ 1.5 MHz、175 fs）。

Q2-3. 「÷2.25 を 2,3,2,2 で近似」できるのはなぜか。何が代償として出るか。

PLL全体が「平均」で一致するように働くので、瞬時分周比が整数でも平均が 2.25 なら実効分周比 2.25 になる。代償：瞬時の位相誤差が常に変動する＝量子化ノイズが帰還信号に乗り、出力PNを悪化させる。周期的に変調すると鋭いスパーになる。

Q2-4. MASH 1-1-1 が「3次ノイズシェーピング」になる仕組みは？

1次DSMを3段カスケードし、前段の量子化ノイズを次段に送る。1・2段目の量子化ノイズは出力合成でキャンセルされ、3段目の量子化ノイズ $Q_{n3}$ にだけ $(1-z^{-1})^3$（3次の離散時間ハイパスフィルタ）が掛かって出てくる。だから低域では量子化ノイズが強く抑圧され、その分高域で増える（PLLのLPFで落とす前提）。

Q2-5. near-integer fractional spur が「PLLの帯域を狭めても消せない」のはなぜ？

フラクショナルスパーは $\alpha f_\text{DSM}$ に出る。微細分解能用途では $\alpha$ が極小になるのでスパーがごく低いオフセット周波数に出る。PLLのLPFで落とすには帯域をそのスパー周波数以下まで下げる必要があるが、そこまで狭めるとVCOノイズが支配的になり総ジッタが悪化する。だから帯域では対処できない。

Q2-6. DTCベースの「キャリブレーション」は何を補正しているか。なぜロック時間に効くか。

DTC（キャンセル信号生成ブロック）のゲイン誤差（LMSで補正）と非線形性（LUTによる区分的プリディストーションで補正）。どちらもブロック特性全体を合わせ込む必要があり収束が遅い（数十µs〜最悪ms）。しかも起動時だけでなく周波数切替のたびに再収束が要る。ループ過渡（数百ns〜数十µs）に上乗せされるので、頻繁に周波数を変える用途では実効ロック時間が跳ね上がる。

Q2-7. 系統③のFIR手法で「主ループの特性を変えてはいけない」のはなぜ？

主ループのLPF特性を狭める形で追加フィルタを入れると、それは単に狭帯域PLLにしたのと同じで、VCOノイズが増えてしまう。狙いは「VCO用の帯域は保ったまま、量子化ノイズにだけ追加のフィルタを効かせる」こと。そのために、同じPLL出力成分＋異なる遅延の量子化ノイズを持つ複数帰還信号を重み付き加算し、量子化ノイズにだけ等価FIRを作る。

第3章 — Dual-Feedback PLL （この論文の中心）

3.1.1 帰還系における入力換算ノイズの増幅

フィードフォワード利得 $A(s)$、帰還利得 $\beta$ の負帰還系（Fig. 3.1a）。開ループ利得 $\beta A(s)\gg1$ のとき、入力換算ノイズ → 出力の閉ループ利得は $1/\beta$。

  • Fractional-N PLL の帰還利得は $\beta=1/N$（分周比の逆数）。→ 入力換算ノイズ（量子化ノイズ含む）は $\omega_\text{UG}$ 以下で $N$ 倍される。
  • 100MHz基準から2.4GHz：$20\log(24)\approx\mathbf{27.6\ dB}$。これが2章で見た「量子化ノイズがPN を激しく悪化させる」根本原因の一つ。
  • 帰還を「割り算」でなく ミキサによる周波数の引き算にすれば（Fig. 3.1b 下）、帰還信号がまるごとミキサ出力に出るので 位相ドメインの帰還利得 $\beta=1$（ユニティ）。ノイズ増幅を回避できる。この着想の追求がこの論文の中核。

PN と ジッタと動作周波数（基本だが重要）

出力を ÷N すると PN は $1/N$、パワースペクトルは $1/N^2$、だが周期は $N$ 倍。位相は「1周期＝$2\pi$」で定義される相対量なので、PN の $1/N$ 減と周期 $N$ 倍が打ち消し合い 積分ジッタは不変。$\sigma\propto\sqrt{\text{積分PN}}\,/\,f_\text{OUT}$。「ノイズ増幅の回避」も、あくまで同じ動作周波数で比べたときのジッタ改善として意味を持つ（この節はここが混乱しやすいと明記されている）。

3.1.2 ノイズ増幅を避けるHMベース帰還

ミキサベースPLLコア（Fig. 3.2）：PD・LF・VCO＋ミキサ＋LO。ミキサ出力は周波数 $f_\text{OUT}-f_\text{LO}$、位相雑音 $\phi_\text{OUT}-\phi_\text{LO}$。帰還＝基準なので $f_\text{OUT}=f_\text{LO}+f_\text{REF}$（出力 ＝ LO ＋ 基準の和）。

$$H_\text{OL}(s)=\frac{K_\text{PD}K_\text{VCO}H_\text{LF}(s)}{s}\quad(\text{従来の式から }N_1\text{ が消えている})$$

伝達関数式意味
$H_\text{VCO,OUT}$$\dfrac{1}{1+H_\text{OL}(s)}$従来と同じHPF。同じVCOフィルタ量には同じ開ループ利得が要る。
$H_\text{EQUIV,OUT}$$\dfrac{H_\text{OL}(s)}{1+H_\text{OL}(s)}$LPF型・DCゲイン1（$N_1$ 倍が無い）＝ノイズ増幅の回避。
$H_\text{LO,OUT}$$-\dfrac{H_\text{OL}(s)}{1+H_\text{OL}(s)}$$H_\text{EQUIV,OUT}$ と同じ、極性反転。

⚠ 単純ミキサの問題：周波数引き込み

4章の理由で $f_\text{REF}\ll f_\text{LO}$ にせざるを得ない → $f_\text{LO}\approx f_\text{OUT}$ → 2つの発振器が引き込み合う（frequency pulling）。LC発振器で磁気結合により顕著、電源・基板結合でも起こる。

解決＝高調波ミキサ HM：$f_\text{HM}=f_\text{OUT}-k f_\text{LO}$（$k$：高調波次数）。$f_\text{OUT}$ と $f_\text{LO}$ が離れる。ただし $f_\text{OUT}\approx k f_\text{LO}$ なので LO の $k$ 次高調波による引き込みリスクは残る → LO の前に、$k$ と互いに素な分周比 $N$ の分周器を入れてさらに低減（Fig. 3.4c）。

3.1.3 HMの実現：Sample-and-Hold（S/H）動作

HMの作り方：①ミキサ＋周波数逓倍器（マルチ位相生成、電力・複雑さ大）、②S/H動作ベース（[59,60,65,66,67]、この論文が採用）。S/H ＝ サンプリング ＋ ホールド。

サンプリング（Fig. 3.5）

  • 時間領域：入力波形に周波数 $f_\text{SH}$（＝LO周波数）のインパルス列を掛ける。
  • 周波数領域：インパルス列は周波数領域でも $f_\text{SH}$ 間隔のインパルス列 → 入力スペクトル（≈単一トーン $f_\text{PLL}$）との畳み込み → $\pm(f_\text{PLL}-k f_\text{SH})$、$\pm f_\text{SH}\pm(f_\text{PLL}-3f_\text{SH})$… が生成。例では $f_\text{PLL}\approx3f_\text{SH}$ なので $\pm(f_\text{PLL}-3f_\text{SH})$ が最低周波数。

ホールド（Fig. 3.6）

  • 時間領域：サンプル値を次のサンプルまで保持＝幅 $T_\text{SH}=1/f_\text{SH}$ の矩形関数との畳み込み。
  • 周波数領域：矩形 → sinc関数との乗算。ノッチは $f_\text{SH}$ の整数倍。
  • 結果：$f_\text{PLL}-3f_\text{SH}\ll f_\text{SH}$ なら最低周波数成分 $\pm(f_\text{PLL}-3f_\text{SH})$ はほぼ減衰なしで残り、高周波成分はノッチ近傍で減衰。→ 高調波次数3のHM出力 $f_\text{HM}=f_\text{PLL}-3f_\text{SH}$ が得られる。

$f_\text{PLL}$ と $f_\text{SH}$ の関係次第で任意の $k$ の HM を作れる。ただし高周波トーンは完全には消えず、非理想性も多い → 4章で詳しく扱う。

3.2 Triple-Loop PLL（先行研究）とその課題

HMベースコアで実際に Fractional-N を作った最初期の一つ [65]。3つのPLL

：メインPLL（HMベース）＋補助 integer-N PLL（HM用LO生成）＋補助 fractional-N PLL（メインの基準生成）。両補助は共通基準。

$$f_\text{OUT}=\left(\frac{kN_1}{M_1}+\frac{N_2+\alpha}{M_2}\right)f_\text{REF}$$

$f_\text{OUT}$ は $f_\text{INT}$ と $f_\text{FRAC}$ の線形結合 → 補助 integer-N で粗調、補助 fractional-N で微調。

ノイズ抑圧の原理

  • 補助 fractional-N PLL は従来型なので、出力に量子化ノイズ／スパーが $N_2+\alpha$ 倍で乗る。
  • それを静的分周器 $\div M_2$ で $M_2$ 分の1に減衰。単体では周波数も $M_2$ 分の1でジッタ不変（無意味）。だがHMベースのメインPLLは「逓倍」でなく「LOでアップコンバート」して高周波を作るので 再増幅されない（メインの入力→出力伝達関数がDCゲイン1）。
  • 結果：DSM量子化ノイズ・非線形起因スパーの寄与を 約 $M_2$ 倍抑圧。補助 integer-N のノイズは $k/M_1$ 倍で乗るが量子化ノイズを含まないので下げやすい。

なお [65] の実装は厳密にはこの図と少し違い、メインにBBPD、補助 integer-N にSPDを使用。

  • PLLが3つ → 電力・面積・設計負荷が大。

3.3 Dual-Feedback PLL（提案）

3.3.1 提案アーキテクチャ（Fig. 3.9）

  • 補助PLLは 1つだけ（integer-N、HM用LO生成＝粗調も担当）。
  • 代わりに メインPLLに2つの帰還経路：①HMベース、②MMDベース。小数チューナブルな信号を「別の補助 fractional-N PLL」ではなく 全体出力＋小数分周器（$\div(N_2+\alpha)$）で作る。それ以外はTriple-Loopと同じ。

ロック時、HMベース帰還 $f_\text{OUT}-\dfrac{k}{M_1}f_\text{INT}$ と MMDベース帰還 $\dfrac{f_\text{OUT}}{N_2+\alpha}$ が等しい →

$$f_\text{OUT}=\frac{k}{M_1}\cdot\frac{N_2+\alpha}{N_2+\alpha-1}\,f_\text{INT}=\frac{kN_1}{M_1}\cdot\frac{N_2+\alpha}{N_2+\alpha-1}\,f_\text{REF}\quad(3.17)$$

  • 粗調：$N_1$（補助PLL）／微調：$N_2+\alpha$（メイン）。
  • シームレスな周波数掃引の要件（$f_\text{OUT,max,fine}\ge f_\text{OUT,coarse}$ より）：
    $$N_1\ \ge\ \frac{(N_2+\alpha)_\text{min}-1}{1-\dfrac{(N_2+\alpha)_\text{min}}{(N_2+\alpha)_\text{max}}}\quad(3.21)$$ 大きな $N_1$（低い基準周波数 or 高い補助PLL出力）と、小さい $(N_2+\alpha)_\text{min}$・大きい $(N_2+\alpha)_\text{max}$ が要る。ただしHM出力周波数に上限があるので $(N_2+\alpha)_\text{min}$ はあまり小さくできない。本論文の全試作はこの不等式を満たすよう設計。

Triple-Loop との違い（ここが提案の肝）

Triple-Loop：量子化ノイズが $N_2+\alpha$ 倍 増幅 → $M_2$ で 減衰 → 再増幅なしで出力。
Dual-Feedback：量子化ノイズ・スパーは メインPLLの入力で発生 → そもそも一度も増幅されずに出力へ。従来 fractional-N 比で 約 $N_2+\alpha$（厳密には $N_2+\alpha-1$）倍改善。
伝達関数のLPF段数：Triple-Loop は2段（補助 fractional-N ＋ メイン）、Dual-Feedback は1段（設計しやすい）。一方ノイズシェーピング周波数は Triple-Loop が $=f_\text{REF}$ 固定、Dual-Feedback は周波数プラン次第で高くできる（ただし上限あり → 5章）。

2つの帰還経路を1つに統合してメインPLLを1ループ扱い。HMベース帰還のゲイン ＝ 1、MMDベース帰還のゲイン ＝ $1/(N_2+\alpha)$、極性が逆なので負帰還系の総帰還ゲインは $1-\dfrac{1}{N_2+\alpha}$。

$$H_\text{OLM}(s)=\frac{K_\text{PDM}K_\text{VCOM}H_\text{LFM}(s)}{s}\left(1-\frac{1}{N_2+\alpha}\right)$$

3.5 従来 Fractional-N PLL との解析的性能比較

「補助PLLを1個増やす価値はあるのか？どんな条件で？」に答える節。各アーキテクチャを、ジッタ／電力について最適設計したときのジッタ-電力パレート曲線で比較する。比較対象：従来 integer-N（上限の目安）、従来 fractional-N、DTCベース fractional-N、Dual-Feedback。

3.5.2 解析フレームワーク（Fig. 3.19）

  • 共通：$f_\text{REF}=50$ MHz、$f_\text{OUT}=3.103$ GHz。Dual-Feedback は外部 integer-N PLL が 4.5GHz → ÷3 で 1.5GHz LO → 2次HMで出力を 103MHz にダウンコンバート。
  • Dual-Feedback 以外は type-II 3次（零点 $\omega_\text{UG}/5$、極 $5\omega_\text{UG}$）。Dual-Feedback は外部PLLに type-I SPD、メインに type-II 3次（外部PLLは広帯域が要るのでSPDのsinc特性も考慮）。
  • ノイズモデル：
    • VCO：$S_\text{nVCO}(f)=\dfrac{4\pi kT(1+\gamma)}{P_\text{VCO}}\left(\dfrac{f_\text{OUT}}{2Qf}\right)^2$（$\gamma=1$、$Q=10$）
    • PD：$S_\text{nPD}(f)=10^{-20}/P_\text{PD}$（1mWで −170 dBc/Hz）
    • DTC：$S_\text{nDTC}(f)=10^{-19}/P_\text{DTC}$（1mWで −160 dBc/Hz、キャリブレーション完璧＝残留量子化ノイズなしと仮定）
    • HM：$S_\text{nHM}(f)=10^{-17}/P_\text{HM}$（1mWで −150 dBc/Hz、メイン入力なので増幅されない）
    • 基準PN −160 dBc/Hz（電力では下がらない＝デバイス固有、とする）。デジタルロジックの電力は無視（プロセスでスケールしノイズとのトレードオフが無いため）。

3.5.3–3.5.4 最適設計の導出と結果

  • 解析的に解くのは複雑（変数多）→ 遺伝的アルゴリズム（GA）で数値的にジッタ-電力パレートを得て、傾向を粗い計算で説明するハイブリッド手法。GA：個体数600、300世代。帯域 10kHz〜（基準の40%）、VCO電力 100µW〜1W など。「1点のFoM最適化」ではなく曲線で比べるのがミソ（実務では「ジッタ100fs必須」なら200fsのPLLはFoMが良くても失格）。
  • Fig. 3.20：
    • integer-N の数値結果は [70] の計算（$P\propto1/\sigma^4$）とよく一致 → 手法の妥当性の傍証。
    • Dual-Feedback も DTCベースも、解析領域全域で 従来 fractional-N より明確に良い → 補助PLL / DTC を足すコストに見合う。
    • Dual-Feedback は DTCベースよりやや良く見える（差は小さく設定依存）。
    • 両者とも integer-N には劣るが、高電力・低ジッタ側で差が縮む（Dual-Feedback：総電力大→メインVCO電力も上げられ最適帯域が狭くなり、量子化ノイズも外部PLLノイズも無視レベルに。DTCベース：DTC電力を上げるとDTCノイズが固定基準PN −160dBc/Hz を下回り、以降 integer-N 並み）。
  • 傾向の説明：integer-N は $P\propto1/\sigma^4$（基準PNを一定に固定するため。$1/\sigma^2$ でない）。fractional-N は $1/\sigma^2$ と $1/\sigma^3$ の間。粗い近似で $\sigma^2\propto\alpha f_\text{UBW}^2+\dfrac{\beta}{P_\text{VCO}f_\text{UBW}}$ に AM–GM を使うと $\propto P_\text{VCO}^{-2/3}$ → $P\propto1/\sigma^3$。DTCベースは低ジッタ側で $1/\sigma^4$、高ジッタ側で $1/\sigma^2$ の合成。
  • Fig. 3.22（PD・HM電力も含めた精密版）：FoM等高線 −240/−250/−260 dB、wireline要求 150 fs（28GHz 8bit ADC, 56/112Gb/s）と wireless要求 200 fs（256-QAM, 3.5% EVM, sub-7GHz, 3GPP 5G）も併記。重要応用がある 100〜200 fs 域で、DTCベースと Dual-Feedback は従来 fractional-N より顕著に良い。Dual-Feedback の最良FoM ≈ DTCベース、≫ 従来 fractional-N、< 従来 integer-N。

結論

Dual-Feedback は従来 fractional-N より大幅に良く、設定次第で DTCベースと同等以上。加えてキャリブレーション不要＝整定時間が短く設計も単純。HMベース構成は多くの高性能用途で有用。

3.6 章のまとめ

HMベース帰還でノイズ増幅を回避 → Triple-Loop（先行）→ 補助PLLを1個減らした Dual-Feedback PLL を提案。sim・測定で有効性（量子化ノイズ ≈33dB改善、フラクショナルスパー −65dBc）、GAハイブリッド解析でジッタ-電力の優位を示した。

💬 第3章 Q&A

1「閉ループ利得が $1/\beta$」って $A/(1+A\beta)$ じゃないの？

そう。ただし $A\beta\gg1$（開ループ利得が十分大きい＝$\omega_\text{UG}$ 以下）で $A/(1+A\beta)\approx1/\beta$ と近似できる。$\omega_\text{UG}$ 以上ではこの近似は崩れ、ノイズは増幅されずに素通り〜減衰する。

2PNが分周で減ってもジッタは減らないって本当？

本当。÷N で PN は $1/N$（パワーで $1/N^2$）に減るが周期が $N$ 倍。位相は「1周期＝$2\pi$」の相対量なので両者が相殺し、時間軸の揺らぎ＝積分ジッタは不変。だから「ノイズ増幅の回避」も同じ動作周波数でのジッタ比較で意味を持つ。$\sigma\propto\sqrt{\text{積分PN}}/f_\text{OUT}$。

3ミキサ帰還だと $f_\text{OUT}=f_\text{LO}+f_\text{REF}$。なぜ「和」？

帰還信号（＝ミキサ出力）の周波数は基準に一致しないとロックしない。ミキサ出力は $f_\text{OUT}-f_\text{LO}$ なので $f_\text{OUT}-f_\text{LO}=f_\text{REF}$、つまり $f_\text{OUT}=f_\text{LO}+f_\text{REF}$。従来PLLの「$f_\text{OUT}=N f_\text{REF}$（積）」とは作り方が根本的に違う。

4周波数引き込み（frequency pulling）とは？分周器型では問題にならなかった？

近い周波数の2発振器（VCOとLO）が磁気・電源・基板結合で互いに周波数を引っ張り合い、PNが悪化する現象。LC発振器で顕著。分周器型は $f_\text{OUT}$ と $f_\text{REF}$ が十分離れているので問題にならない。ミキサ型は $f_\text{OUT}\approx f_\text{LO}$ になりがちで問題化する。

5$k$ 次高調波ミキサにしても $f_\text{OUT}\approx k f_\text{LO}$ で引き込むのでは？

残る。$k f_\text{LO}$ 高調波による引き込みリスクは消えない。だから LO の前に「$k$ と互いに素な分周比 $N$」の分周器を入れる。互いに素なら高調波成分が帰還経路で重なりにくく、引き込みを抑えられる（Fig. 3.4c）。

6Triple-Loop と Dual-Feedback、量子化ノイズの扱いはどう違う？

Triple-Loop：補助 fractional-N PLL で量子化ノイズが $N_2+\alpha$ 倍増幅 → $\div M_2$ で減衰 → HMベースメインPLL（DCゲイン1）で再増幅なし。正味 $\approx M_2$ 倍改善。
Dual-Feedback：量子化ノイズはメインPLLの入力で発生するのでそもそも一度も増幅されない。従来比 $\approx N_2+\alpha-1$ 倍改善。伝達関数のLPF段数も 2段→1段で設計が楽。

7なぜ Dual-Feedback は補助PLLが1つで済む？

Triple-Loop で「補助 fractional-N PLL」が担っていた小数チューナビリティを、全体出力を小数分周器 $\div(N_2+\alpha)$ に通した信号（＝第2の帰還経路）で代替するから。補助 integer-N PLL（HM用LO＋粗調）だけ残せばよい。

8式(3.17)の $\frac{N_2+\alpha}{N_2+\alpha-1}$ はどこから来る？

2経路の帰還ゲインの合成。HM帰還がゲイン1、MMD帰還がゲイン $1/(N_2+\alpha)$、極性が逆なので総帰還ゲインが $1-\frac{1}{N_2+\alpha}=\frac{N_2+\alpha-1}{N_2+\alpha}$。ロック条件を解くとその逆数が $f_\text{OUT}$ の式に現れる。$N_2+\alpha$ が大きければ ≈ 1 なので、ほぼ $f_\text{OUT}=\frac{kN_1}{M_1}f_\text{REF}$。

9なぜ「1点のFoM」ではなく「曲線」で比較する？

実務ではジッタか電力の一方がスペックとして与えられ、他方をその制約内で最適化する。ジッタ100fs必須のシステムに、FoMがいくら良くても200fsのPLLは使えない。ジッタ-電力の最適曲線（パレート）で比べると「どの方式がどの領域に向くか」まで分かる。

✅ 第3章 理解度確認問題

Q3-1. 「分周器帰還だと入力換算ノイズが N 倍される」を、$\beta$ と閉ループ利得の式で説明せよ。

入力換算ノイズ→出力の閉ループ利得は $A\beta\gg1$ で $\approx1/\beta$。分周器帰還では $\beta=1/N$ なので $1/\beta=N$。よって $\omega_\text{UG}$ 以下で入力側ノイズ（量子化ノイズ含む）は $N$ 倍。100MHz→2.4GHz なら $20\log 24\approx27.6$ dB。

Q3-2. HMベースコアの $H_\text{OL}(s)$ が従来PLLとどう違うか。それが $H_\text{EQUIV,OUT}$ のDCゲインにどう効くか。

$H_\text{OL}=K_\text{PD}K_\text{VCO}H_\text{LF}(s)/s$ で、従来の $N_1 s$ の $N_1$ が無い（帰還が引き算＝ユニティゲイン）。$H_\text{EQUIV,OUT}=H_\text{OL}/(1+H_\text{OL})$ は従来と同じLPF形だがDCゲインが $N_1$ でなく1。だから入力換算ノイズ（量子化ノイズ）が出力で増幅されない。

Q3-3. なぜ単純ミキサでなく高調波ミキサ（HM）を使うのか。HMでも残るリスクとその対策は？

単純ミキサだと $f_\text{REF}\ll f_\text{LO}$（4章の理由）により $f_\text{LO}\approx f_\text{OUT}$ となり周波数引き込みが起きる。HM（$f_\text{HM}=f_\text{OUT}-k f_\text{LO}$）なら $f_\text{OUT}$ と $f_\text{LO}$ が離れる。残るリスクは $f_\text{OUT}\approx k f_\text{LO}$（LOの$k$次高調波による引き込み）。対策は LO前に $k$ と互いに素な分周比の分周器を入れること。

Q3-4. S/H が HM として働く仕組みを「サンプリング」「ホールド」の周波数領域で。

サンプリング：時間領域でインパルス列（周波数 $f_\text{SH}$）を掛ける＝周波数領域で $f_\text{SH}$ 間隔インパルス列との畳み込み → $\pm(f_\text{PLL}-k f_\text{SH})$ などの差周波数成分が生成。ホールド：幅 $T_\text{SH}$ の矩形との畳み込み＝周波数領域で sinc（ノッチが $f_\text{SH}$ の整数倍）との乗算 → 高周波成分がノッチ付近で減衰し、最低周波数の $f_\text{HM}=f_\text{PLL}-k f_\text{SH}$ が残る。

Q3-5. 式(3.21)のシームレス掃引不等式が要求すること（4つ）を挙げよ。

微調範囲が粗調ステップを覆う条件。①大きな $N_1$（＝低い基準周波数か高い補助PLL出力）、②小さい $(N_2+\alpha)_\text{min}$、③大きい $(N_2+\alpha)_\text{max}$。ただし④HM出力周波数に上限があるので $(N_2+\alpha)_\text{min}$ はあまり小さくできない、という制約がある。本論文の全試作はこれを満たすよう設計されている。

Q3-6. 3.4節の試作で、integer モードと fractional モードのPNの差が意味するものは？結果は？

その差 ＝ DSM量子化ノイズの寄与。従来 fractional-N なら大きな山になるが、Dual-Feedback 試作ではほぼ無視できるレベル → ノイズ増幅の回避によって量子化ノイズを抑圧できたことの直接的証拠。sim では抑圧量 ≈「分周比 −1」＝約33 dB。

Q3-7. 5% CP電流ミスマッチを故意に付加する実験は何を確かめている？結果は？

非線形起因のフラクショナルスパーも、量子化ノイズと同じ「増幅回避」の恩恵を受けるか。結果：従来 −33 dBc、提案 −66 dBc の 33 dB差 ＝ 予測される $N.\alpha-1$ 倍抑圧と一致。

Q3-8. 3.5節でジッタ-電力曲線を「解析だけ」でなく「GA（遺伝的アルゴリズム）」で出す理由は？

Dual-Feedback のような多変数構成は最適ジッタ-電力関係を解析的に閉形式で出すのが困難（integer-N ですら [70] は多数の近似を要する）。そこで GA で数値的にパレート曲線を求め、その傾向を粗い計算＋近似（AM–GMなど）で事後説明するハイブリッド手法をとる。

Q3-9. Fig. 3.20 で「高電力・低ジッタ側では Dual-Feedback / DTCベースが integer-N に近づく」のはなぜ？

Dual-Feedback：総電力を上げるとメインVCO電力も上げられ最適帯域が狭くなる → 量子化ノイズも外部PLLノイズ（メインPLLのLPFで落ちる）も無視レベルに。DTCベース：DTC電力を上げるとDTCノイズが固定基準PN(−160dBc/Hz)を下回り、以降DTCの電力・ノイズ寄与が無視できて integer-N 並みになる。

第4章 — HMベースPLLのオフセットスパー解析

4.1 問題設定：S/H動作が生むオフセットスパー

HMをS/Hで実現する代償として、HM出力に2種類の不要トーンが出る（Fig. 4.1）。先行研究は発生機構の説明もLPF設計指針も示していない。この章の貢献は発生機構の解明・位置と振幅の閉形式導出・LPF設計指針。

4.2 背景理論

4.2.1 PFD/CP の位相サンプリング動作

  • PFD/CP は位相差を連続的に出すのではなく、入力の立ち上がりエッジでのみ動作。CPの電流パルスは1基準周期よりずっと狭い → PFD/CP は「真の（連続時間の）入力位相差」に周波数 $f_\text{HM}$（＝PD入力周波数＝HM出力周波数）のインパルス列を掛けるブロックとみなせる。
  • 周波数領域：入力位相差スペクトルが $f_\text{HM}$ 間隔のインパルス列と畳み込まれ、$f_\text{HM}$ とその高調波にコピーが現れる。
  • 入力位相差に高周波成分が無く帯域が狭ければ問題ないが、HM出力は LO 周波数（$\gg f_\text{HM}$）付近の位相成分を含むので、この折り返しが効いてくる。XOR PD や SPD も離散時間動作なので同様。

4.2.2 信号スペクトルとその位相スペクトルの関係

$V(t)=A\sin(\omega_c t+\phi_n(t))$、$|\phi_n|\ll1$ とすると

$$V(t)\approx A[\sin(\omega_c t)+\phi_n(t)\cos(\omega_c t)]$$

$\phi_n(t)=A_n\sin(\omega_n t)$ の1成分に注目すると

$$V(t)\approx A\sin(\omega_c t)+\frac{A A_n}{2}\big[\sin((\omega_c+\omega_n)t)-\sin((\omega_c-\omega_n)t)\big]$$

→ 信号スペクトル ＝ PNスペクトルを搬送波の両側にコピーしたもの（Fig. 4.3）。HMの動作は電圧領域で解析するが、PLL全体はHM出力を過剰位相（excessive phase）で扱うので、この両者を行き来する変換が必要。

4.3 不要トーンの発生機構

4.3.1 Type-A スパー（高周波トーン）

  • ホールドの sinc のノッチは $f_\text{SH}$ の整数倍。だが高周波トーンは $\pm f_\text{SH}\pm f_\text{HM}$、$\pm2f_\text{SH}\pm f_\text{HM}$… ＝ ノッチから $\pm f_\text{HM}$ ずれた位置にある → 完全には消えない。
  • 位相領域に変換すると、これらは $f_\text{SH}$ の整数倍のスパーになる。PFD/CP の位相サンプリング（$f_\text{HM}$）で低周波へエイリアス。$f_\text{SH}$ が $f_\text{HM}$ の整数倍に近いと、スパーがごく低周波に出て PLL の LPF で落ちない。
  • → S/H直後のpost-LPFで位相検出前に抑える。

4.3.2 Type-B スパー（低周波トーン）

  • S/H入力（PLL出力）の高次高調波を考える必要がある（Fig. 4.5、$k=3$ の例）。HM出力には：望みの $f_\text{HM}=f_\text{PLL}-3f_\text{SH}$、Type-Aの元になる $\pm(f_\text{SH}-f_\text{HM})$ 等、$f_\text{HM}$ の整数倍（無害、DCへ落ちる）、そして$f_\text{PLL}$ の高調波 と $f_\text{SH}$ の高調波の相互作用。
  • 例：$11f_\text{PLL}$ と $34f_\text{SH}$ → $34f_\text{SH}-11f_\text{PLL}=f_\text{SH}-11f_\text{HM}$。高次になるほどトーンが低周波に寄る。$f_\text{SH}$ がたまたま $12f_\text{HM}$ に近いと $f_\text{SH}-11f_\text{HM}\approx f_\text{HM}$ ＝ 望みの信号のすぐ近くに来て、後段LPFで落とせない。
  • → S/H前のpre-LPFで高次高調波を落としてから S/H に入れる。

4.4 スパーの位置と振幅の解析

4.4.1 位置

Type-A も Type-B も 同じ周波数に出る：

$$\Delta f=|f_\text{SH}-l\,f_\text{HM}|,\qquad \left(l-\tfrac12\right)f_\text{HM}

＝$f_\text{SH}$ と、それに最も近い $f_\text{HM}$ の整数倍との差。$f_\text{SH}$ が $f_\text{HM}$ の整数倍にごく近いとスパーは低周波に出て PLL の LPF で落ちない。高調波（$2\Delta f$, $3\Delta f$…）も出るが基本波より小さい。

4.4.2 Type-A の振幅

陰的 sinc 関数 $F_\text{SINC}(f,f_\text{SH})\equiv\dfrac{\sin(\pi f/f_\text{SH})}{\pi f/f_\text{SH}}$ を定義。

$$U_A[\text{dBc}]=10\log\!\left[\frac{|H_\text{PLL,cl}(\Delta f)|^2\big(F_\text{SINC}^2(f_\text{HM}-f_\text{SH},f_\text{SH})+F_\text{SINC}^2(f_\text{HM}+f_\text{SH},f_\text{SH})\big)}{2\,F_\text{SINC}^2(f_\text{HM},f_\text{SH})}\right]$$

  • $\pm(f_\text{SH}-f_\text{HM})$ と $\pm(f_\text{SH}+f_\text{HM})$ はノッチから等距離なので減衰はほぼ同じ → 平均で近似し、搬送波の減衰 $F_\text{SINC}^2(f_\text{HM},f_\text{SH})$ で規格化。$|H_\text{PLL,cl}(\Delta f)|$ はHMベースPLLの閉ループ伝達関数。
  • Type-A が最大：$f_\text{SH}$ 最小・$f_\text{HM}$ 最大（トーンがノッチから遠い＋sincが急峻）・$f_\text{SH}$ が $f_\text{HM}$ の整数倍に近い・$\Delta f$ が小さい。→ 最悪値 $U_{A,\text{max}}$（式4.8）。

4.4.3 Type-B の振幅

sinc の影響は小さいが、S/H入力の高調波組成と post-LPF に依存。矩形波（奇数次高調波のみ）を例に：

  • $f_\text{SH}\approx2m\,f_\text{HM}$（偶数倍）：$2m-1$ 次と $2m+1$ 次が搬送波の両側に等距離・ほぼ同振幅。フーリエ級数で $2m+1$ 次の振幅は $1/(2m+1)$。
    $$U_B[\text{dBc}]=10\log\!\left[\frac{(2m-1)^{-2}+(2m+1)^{-2}}{2}\right]$$
  • $f_\text{SH}\approx(2m+1)f_\text{HM}$（奇数倍）：$2m+1$ 次が DC 近く、$2m-1$・$2m+3$ 次が $2f_\text{HM}$ 近く（post-LPF で抑圧）→ 片側だけになる。近似：片側トーンが両側に半分のパワーで出るとみなす。
    $$U_B[\text{dBc}]=10\log\!\left[\frac{(2m+1)^{-2}}{2\,|H_\text{post,LPF}(j2\pi f_\text{HM})|^2}\right]$$

4.4.4 挙動シミュレーション（検証）

  • Type-A 検証（Fig. 4.9）：VCO 正弦波（高調波なし）→ Type-A のみ観測。$R=10.5$ kΩ, $C_1=45.6$ pF, $C_2=5.07$ pF, $I_\text{CP}=20$ µA, $K_\text{VCO}=30$ Mrad/V, 帯域1MHz。$f_\text{SH}=800.1$ MHz, $f_\text{HM}=100$ MHz ($f_\text{SH}\approx8f_\text{HM}$) → スパー $\Delta f=100$ kHz とその倍数。式4.7とよく一致。
  • 依存性（Fig. 4.11）：スパーは $f_\text{HM}$↑（ノッチから遠い）で大、$f_\text{SH}$↓（ノッチ付近の sinc が急峻）で大 → 予測通り。
  • post-LPF効果（Fig. 4.12–13）：1次LPF 帯域100MHz → $f_\text{HM}$ で −3 dB, $f_\text{SH}$ で −21 dB ＝ 相対18 dB → スパー −17.86 − 18 ≈ −35.86 dBc（sim一致）。
  • Type-B 検証（Fig. 4.14–16）：VCO 矩形波＋Type-A抑圧用に4次LPF（帯域$2f_\text{HM}$）。偶数ケースは式4.9とよく一致、奇数ケースは約1 dB小さめ（$2f_\text{HM}$付近の高調波を無視した＋片側近似のため。前者を入れると+0.26 dB補正）。実用上 1 dB 誤差は問題なし。
  • pre-LPF効果（Fig. 4.17–18）：$f_\text{SH}\approx8f_\text{HM}$ なので 7・9次が搬送波近くへ落ちる。1次LPF 帯域2.5GHz → $f_\text{OUT}$ で −3 dB, 7/9次で −17/−19 dB ＝ 相対15 dB。

4.5 S/H の RC 時定数の考慮

  • 理想S/Hはオン時入力インピーダンス0・オフ時∞。実際はスイッチのオン抵抗＋分離バッファ出力インピーダンス $R$ が、サンプリング容量 $C$ と RC時定数を作る（[66,67] Iizuka & Abidi の FET-R-C 解析を利用）。
  • 効果：①RCのLPFで入力波形が減衰・位相シフト、②前周期のサンプル値がスイッチオン直後に過渡応答を作る。SFG（Fig. 4.19）で表現。
  • ある近似条件下では簡略SFG（Fig. 4.20）：理想S/Hの周波数変換＋ZOHに加え、ダウンコンバート前に余分な sinc、後に余分な1次LPF（帯域 $D/RC$）が入る。適切に設計すればこれらもオフセットスパー抑圧に寄与する。スパーの発生機構と対策の方向は不変。

4.6 LPF設計ケーススタディ（回路レベル）

HM設計フロー：①最悪ケース周波数設定を確定 → ②pre/post LPF無しでHMを作り、1段目サンプラの帯域・S/H入力の高調波レベル・クロックデューティから必要なフィルタ量を計算 → ③pre/post LPF を設計 → ④挿入して HM 動作・最終オフセットスパーをシミュ確認。

最悪ケース：$f_\text{SH}$ が最小値付近・$f_\text{HM}$ が最大値付近・$f_\text{SH}$ が $f_\text{HM}$ の整数倍に近い・$\Delta f$ が PLL帯域より十分低い。Type-B の高調波組成は次数が上がるほど小さくなるので、最悪ケースは Type-A と同じとみなせる。

4.7 章のまとめ

S/H由来のオフセットスパー（Type-A/Type-B）の2つの発生機構を明確化し、位置（$\Delta f=|f_\text{SH}-l f_\text{HM}|$）と振幅を閉形式で導出。RC時定数の影響も取り込み、pre/post LPF の設計指針をケーススタディで実証。全て挙動・回路シミュとよく一致。

💬 第4章 Q&A

1Type-A と Type-B、結局何が違うの？

出る場所が違う。Type-A は HM出力の高周波（$f_\text{SH}\pm f_\text{HM}$ 付近）に出て、位相検出のサンプリングで低周波へ折り返される。Type-B は最初から搬送波の近くに出る（$f_\text{PLL}$ と $f_\text{SH}$ の高次高調波どうしの相互作用で）。だから Type-A は S/H の後、Type-B は S/H の前にLPFが要る。周波数軸上は結局どちらも同じ $\Delta f$ に出る。

2なぜ「PFD/CP はインパルス列を掛けるブロック」とみなせる？

PFD/CP は連続的に位相差を出すのではなく、入力の立ち上がりエッジでだけ電流パルスを出す。パルス幅は1周期よりずっと狭い。だから「真の連続時間の位相差 × 周波数 $f_\text{HM}$ のインパルス列」と近似できる。周波数領域では位相差スペクトルが $f_\text{HM}$ 間隔でコピーされる（＝サンプリング＝エイリアス）。

3「電圧領域スペクトル ↔ 位相領域スペクトル」の変換はなぜ要る？

HMの動作（S/H・sinc・高調波の混ざり合い）は電圧波形で考えるのが自然だが、PLLの線形モデルは過剰位相を変数にする。$V(t)=A\sin(\omega_c t+\phi_n)$ を微小近似すると「信号スペクトル ＝ PNスペクトルを搬送波の両側にコピーしたもの」。この関係で、電圧領域で求めたHM出力トーンを位相領域のスパーに換算できる。

4なぜ「$f_\text{SH}$ が $f_\text{HM}$ の整数倍に近い」と最悪なの？

スパーは $\Delta f=|f_\text{SH}-l f_\text{HM}|$ に出る。$f_\text{SH}$ が $l f_\text{HM}$ にごく近いと $\Delta f$ がごく小さくなり、PLLの閉ループLPFで落とせない（帯域内）。$|H_\text{PLL,cl}(\Delta f)|$ が最大＝スパーがそのまま出力に出る。

5Type-A が「$f_\text{SH}$ 小・$f_\text{HM}$ 大」で大きくなる直感的理由は？

不要トーンは sinc のノッチ（$f_\text{SH}$ の整数倍）から $\pm f_\text{HM}$ ずれた位置にある。$f_\text{HM}$ が大きいほどノッチから遠く減衰が浅い。$f_\text{SH}$ が小さいほどノッチ付近の sinc の傾きが急で、同じ $f_\text{HM}$ ずれでも相対的に減衰が浅い。一方で望みの信号（$f_\text{HM}$）自体は sinc 帯域が狭まり高い周波数に来るので余計に減衰する。

6pre-LPF を「2つの分離バッファの間」に置くのはなぜ？

バッファ前だとVCO由来の高調波しか抑えられない。バッファ後（S/H直前）だとLPFがS/Hの見る出力インピーダンスを変えてしまい設計が複雑化。間に置けば、バッファが発生する高調波を抑えつつS/Hの出力インピーダンスは触らずに済む。ただしVCO出力自体に大きな高調波があるならバッファ前でもよい。

✅ 第4章 理解度確認問題

Q4-1. Type-A スパーの発生を3ステップで説明せよ。

①ホールドの sinc のノッチは $f_\text{SH}$ の整数倍だが、不要トーンは $f_\text{SH}\pm f_\text{HM}$ などノッチから $\pm f_\text{HM}$ ずれた位置にあり完全には消えない。②位相領域では $f_\text{SH}$ の整数倍のスパーになる。③PFD/CP の位相サンプリング（$f_\text{HM}$）で $\Delta f=|f_\text{SH}-l f_\text{HM}|$ にエイリアス。$f_\text{SH}$ が $f_\text{HM}$ の整数倍に近いと低周波に出てPLLで落ちない。

Q4-2. Type-B スパーの発生を説明せよ。なぜ pre-LPF で対策するのか。

S/H入力（PLL出力）の高次高調波と $f_\text{SH}$ の高次高調波の相互作用で $f_\text{SH}-n f_\text{HM}$ のトーンが生じる。次数が上がるほど低周波に寄り、$f_\text{SH}$ が $f_\text{HM}$ の整数倍に近いと $\approx f_\text{HM}$ ＝搬送波のすぐ近くに来る。搬送波近傍なので後段LPFでは落とせない → S/H の前で高次高調波を抑えるしかない。

$\pm(f_\text{SH}-f_\text{HM})$ と $\pm(f_\text{SH}+f_\text{HM})$ はノッチから等距離なので減衰量がほぼ同じ → 位相領域の単一スパーに変換するには等振幅とみなす必要があり、平均で近似する。分母 $2F_\text{SINC}^2(f_\text{HM},f_\text{SH})$ は搬送波（望みの信号）の減衰で規格化し、相対振幅[dBc]にするため。

Q4-6. HM設計フロー4ステップを述べよ。

①最悪ケース周波数設定を確定（$f_\text{SH}$ 最小・$f_\text{HM}$ 最大・$f_\text{SH}$ が $f_\text{HM}$ の整数倍に近い・$\Delta f$ 小）。②pre/post LPF無しでHMを作り、1段目サンプラ帯域・S/H入力高調波レベル・デューティから必要フィルタ量を計算。③pre/post LPF を設計。④挿入してHM動作を確認 → PLLを閉じて最終オフセットスパーがスペックを満たすか確認。

第5章 — Nested-PLLによる位相領域フィルタ（PDLPF）を併用した Dual-Feedback PLL

5.1 リングVCOで周波数シンセをやりたい動機

  • リングVCO の利点：小面積・磁気結合なし・広いチューニングレンジ・多相出力が簡単。
  • 欠点：同じ電力なら PN が LC-VCO より大幅に悪い。→ 多くの用途で使いにくい。
  • 2章の通り、VCO PN 抑圧のために帯域を広げると、基準系ノイズ・DSM量子化ノイズが増える（トレードオフ）。リングVCO はPNが悪いぶん帯域をさらに広げたい → 量子化ノイズを別手段で抑える必要がより切実。

5.2 キャリブレーション不要の先行手法2つと、その限界

5.2.1 HMベース帰還（Dual-Feedback, 3章）の限界＝ノイズシェーピング周波数の頭打ち

  • HM出力には Type-A トーン（$f_\text{LO}\pm f_\text{HM}$ 付近）がある。$f_\text{HM}$ が $f_\text{SH}$ に対して十分小さくないと、望みの信号を減衰させずに不要トーンだけ落とすのが困難。
  • インダクタレス実装では $f_\text{SH}$ を大きくしにくい（リングVCO の FoM は高周波で段数が減って劣化）。→ $f_\text{HM}$ も大きくできない。
  • ロック後は ノイズシェーピング周波数 ＝ HM出力周波数 なので、これが Dual-Feedback では頭打ち。3章の LC-VCO 実装では「増幅回避だけで量子化ノイズを無視レベルにできた」ので問題なかったが、リングVCO は PN が悪く帯域を広げる必要があり、増幅を回避しても量子化ノイズが出力PNを大きく劣化させる。

5.2.2 分割帰還分周 ＋ Nested-PLL 位相領域LPF（PDLPF）[79]

  • 帰還分周器を2分割して ノイズシェーピング周波数を上げる＋ PDLPF（Nested PLL）をアンチエイリアスフィルタとして使う（PLLは入力→出力でLPF特性なので、2段目分周器の前で高周波量子化ノイズを落としエイリアスを防ぐ）。[51] より古く、分割帰還分周の元祖。
  • 限界①：Nested PLL はメインPLLの開ループ伝達関数に影響する（[55–58] のFIRと違う点）。Nested PLL 帯域を自由に選べず、位相マージン確保のためメインPLL帯域より十分広くする必要（[79]で ±10%変動込み 2.5倍、実用5〜6倍）。一方アンチエイリアスには狭い帯域が要る → 結局メインPLL帯域が制限される（リングVCO PN 抑圧のため広げたかったのに）。
  • 限界②：Nested PLL 自体のノイズがループ内で増幅される（1段目分周器の帰還ゲイン $1/N_1$）。Nested VCO・PD の寄与が大きく、電力／ノイズのオーバーヘッド。

5.3 提案：分割帰還分周＋PDLPF を Dual-Feedback の「中に」入れる

アイデアはシンプル：2つの先行手法を組み合わせるだけ。だが組み合わせることで両者の利点を保ちつつ両者の欠点を消す。

5.3.1 提案アーキテクチャ（Fig. 5.3）の利点

  • ノイズ増幅の回避（Dual-Feedback の特性）。
  • ノイズシェーピング周波数を上げられる（HMの動作に縛られない）。
  • PDLPF による追加フィルタリング。
  • Nested PLL が全体安定性に影響しない → 帯域を自由設計可（分周器経路のゲインが $1/N_1N_2$、HM経路が1なので HM ループが支配的）。例：メインを広帯域でメインVCO PN 抑圧、Nested をやや狭帯域で量子化ノイズフィルタ。
  • Nested PLL 自体のノイズも増幅回避で抑圧 → 低ノイズ／低電力オーバーヘッドで実装可。

$$f_\text{OUT}=k f_\text{LO}+f_\text{HM}=\frac{kN_1N_2}{N_1N_2-1}f_\text{LO},\qquad f_\text{DSM}=N_2 f_\text{HM}$$

💬 第5章 Q&A

13章の Dual-Feedback で「増幅回避」できたのに、なぜ5章でさらに手を入れる必要が？

3章は LC-VCO 想定。LC-VCO は PN が良いので帯域を狭くでき、増幅回避だけで量子化ノイズを無視レベルにできた。リングVCO は PN が悪いので帯域を広げざるを得ず、増幅を回避しても（帯域内に残る）DSM量子化ノイズが出力PNを大きく劣化させる。しかも Dual-Feedback はノイズシェーピング周波数が HM出力周波数で頭打ち。だから「シェーピング周波数を上げる＋追加フィルタ」が要る。

2なぜ Dual-Feedback ではノイズシェーピング周波数が頭打ちになる？

ロック後はノイズシェーピング周波数 ＝ HM出力周波数 $f_\text{HM}$。$f_\text{HM}$ を大きくするには $f_\text{SH}$ をもっと大きくする必要があるが、リングVCO は高周波で段数が減り FoM が悪化するので $f_\text{SH}$ を上げにくい。しかも $f_\text{HM}$ が $f_\text{SH}$ に近すぎると Type-A トーンと望みの信号を分離できない（4章）。だから $f_\text{HM}$＝シェーピング周波数に上限がある。

3従来 [79] では Nested PLL 帯域を自由に選べないのに、提案ではなぜ自由？

従来（単一ループ）は開ループ利得が $\propto G_\text{CL,nest}(s)/(N_1N_2)$ ＝ Nested の閉ループ特性が式全体に掛かるので、Nested 帯域が主PLLの位相マージンを直接左右する。提案は分周器経路のゲインが $1/(N_1N_2)$、HM経路が1で、HM ループが開ループ利得を支配する。$1-G_\text{CL,nest}/(N_1N_2)\approx1$ なので Nested 帯域は安定性にほぼ効かない。

4「$N_1N_2$ 倍の抑圧改善」はどこから？

従来単一ループ [79] では DSM量子化ノイズも Nested PLL PN も、1段目分周器の帰還ゲイン $1/N_1$ によって $N_1$ 倍増幅される。提案では HM帰還のおかげで増幅されず、$H_\text{DSM,OUT}$・$H_\text{NEST,OUT}$ のDCゲインが $1/N_2$ で減衰。差し引き $N_1\times N_2 = N_1N_2$ 倍の改善。

53つのPLLが順にロックするなら、ロック時間は合計になるのでは？

ならない。3つの過渡は大きく時間的に重なるので、全体のロック時間は最も遅いループで律速される。sim では全体460 ns に対し個別ロック時間の単純和は1.11 µs。いずれにせよ DTC のキャリブレーション収束（数十µs〜ms）よりはるかに速い。

63章では Dual-Feedback が DTC に勝っていたのに、5章（リングVCO）では負けるのはなぜ？

リングVCO は PN が悪く最適ループ帯域が広くなる。Dual-Feedback の残留ノイズは整形された量子化ノイズ（$f^2$ で立ち上がる）で、帯域を広げると寄与が増える。DTCベースの残留ノイズは平坦な白色ノイズで帯域を広げても相対的に不利になりにくい。だから広帯域が要るリングVCO では DTC のほうが有利になる。

✅ 第5章 理解度確認問題

Q5-1. リングVCOの利点と欠点を挙げ、なぜ「量子化ノイズ抑圧」がより切実になるか説明せよ。

利点：小面積・磁気結合なし・広チューニングレンジ・多相出力。欠点：同電力でPNがLC-VCOより大幅に悪い。→ VCO PN を抑えるにはループ帯域を広げるしかないが、帯域を広げると基準系ノイズ・DSM量子化ノイズが増える。だから量子化ノイズを帯域以外の手段で強力に抑えないと、リングVCOでは良いジッタが出せない。

Q5-2. 従来 [79] の2つの限界を述べよ。

①Nested PLL がメインPLLの開ループ伝達関数に影響する → 安定性のため Nested 帯域をメイン帯域の5〜6倍に広げる必要があり、一方アンチエイリアスには狭帯域が要る → 結局メインPLL帯域が制限される。②Nested PLL 自体のノイズが1段目分周器の帰還ゲイン $1/N_1$ でループ内増幅され、電力／ノイズオーバーヘッドになる。

Q5-3. 提案の $H_\text{OL}(s)$ を書き、なぜ Nested 帯域が安定性に効かないか説明せよ。

$H_\text{OL}(s)=\dfrac{K_\text{PD}K_\text{VCO}H_\text{LF}(s)}{s}\left(1-\dfrac{G_\text{CL,nest}(s)}{N_1N_2}\right)$。$|G_\text{CL,nest}|\le1$、$N_1N_2$ は大きいので括弧内 ≈ 1。よって $H_\text{OL}\approx K_\text{PD}K_\text{VCO}H_\text{LF}(s)/s$（HMコアそのまま）で、Nested の閉ループ特性はごく小さな摂動にしかならない。従来は $G_\text{CL,nest}/(N_1N_2)$ が式全体に掛かるので事情が全く違う。

Q5-4. $f_\text{DSM}=N_2 f_\text{HM}$ が意味することは？

ノイズシェーピング周波数が HM出力周波数の $N_2$ 倍になる。Dual-Feedback 単体ではシェーピング周波数が $f_\text{HM}$ で頭打ちだったのが、分割帰還分周（2段目 ÷$N_2$）で $N_2$ 倍に引き上げられる。→ 量子化ノイズをより高域へ逃がせる。

Q5-5. Fig. 5.17 のIPN内訳から読み取れる「提案の狙い通りだった点」は？

Nested PLL の寄与が3%、DSM が0%、メインCP が0%。つまり「Nested PLL を足したのにそのノイズは無視レベル」「量子化ノイズも無視レベル」＝HM帰還による増幅回避＋PDLPFの効果が設計通り。総ジッタはメインVCO(42%)と外部PLL(54%)で決まっており、これらは6章のテーマ。

第6章 — フィードフォワード雑音キャンセルを備えた Dual-Feedback PLL

6.1 マルチループPLLの根本課題＝余分なVCO

  • 従来 single-loop fractional-N のノイズ源：等価基準換算PN、VCO PN、DSM量子化ノイズ。
  • Dual-Feedback のノイズ源：外部PLLの等価基準換算PN、2つのVCOの PN、DSM量子化ノイズ（メインPLLの等価基準換算PN・HM PN は増幅されないので無視）。
  • 量子化ノイズは増幅回避で減ったが、代わりに 外部VCO1個ぶんの PN が乗る。この余分なVCOのオーバーヘッドを無視レベルにするのがこの章の目標。

6.2 従来のノイズ抑圧手法

6.2.1 広帯域PLL

  • メインPLL・VCO は最適帯域でジッタ要求を満たし、外部PLL は低電力・広帯域にする。外部PLL PN はメインPLLでLPFされるので、外部帯域 ≫ メイン帯域 なら外部VCO PN を無視レベルにできる。
  • 限界：高周波基準はコスト高。HMベースの周波数プランに難（$f_\text{OUT}=k f_\text{SH}+f_\text{HM}$、$f_\text{REF}$ が高いと $f_\text{HM}$ が広範囲をカバーせねばならない）。$f_\text{BW}\le0.5f_\text{REF}$ の壁。$f_\text{BW}/f_\text{REF}$ が大きいとプロセス変動で peaking / 不安定。広帯域は type-I にせざるを得ず（Gardner's limit回避）、type-I は DC に1極だけ＝低周波VCO PN 抑圧が非効率（HPF が 20 dB/dec）。積分パス追加で改善できるが比例パスよりゲインを小さくせねばならず限定的。

6.2.2 PLL後段のVCDLベース補正

狭〜中帯域PLLで安定な信号を作り、その出力に VCDL（電圧制御遅延線） を付けてVCO PN を追加抑圧。2形態：

6.3 提案：電圧領域フィードフォワード位相雑音キャンセル

6.3.1 コンセプト（Fig. 6.5）

  • フィードフォワード型VCDLと同様に、外部PLLのPD出力（＝PLL出力PN の情報を持つ）を取る。ただしVCDLを制御するのではなく、そのままメインPLLのPD出力に足し込む → 外部VCO の PN成分を打ち消す。
  • 高速VCDLが不要。理由：カスケードPLLでは外部PLLの出力PN成分が2段目PDの出力に現れ、そこでは信号がDCへダウンコンバートされて低周波になっている → 電圧領域でそのまま加算処理できる。single-loop PLLの出力は最終信号（時間領域）なので、キャンセルには時間領域＝VCDLが要る。
  • この技法は Dual-Feedback 以外のノイズキャンセル構成にも使える。

6.3.2 ノイズキャンセル解析（Fig. 6.6）

$K_\text{FF}$ ＝ フィードフォワード経路のゲイン。$H_\text{OL1}$, $H_\text{OLM}$ は Dual-Feedback と同じ。メイン系ノイズ（$\phi_\text{nVCOM}$, $\phi_\text{nEQUIVM}$, $\phi_\text{nDSM}$）の伝達関数はキャンセル無し版と不変（量子化ノイズ・メイン入力換算PN は同じ増幅回避）。

外部VCO PN → 出力：

$$H_\text{VCO1,OUT}(s)=\left(\frac{kK_\text{PDM}}{M_1}-\frac{K_\text{FF}K_\text{PD1}}{N_1}\right)\frac{1}{1+H_\text{OL1}(s)}\cdot\frac{1}{K_\text{PDM}}\cdot\frac{H_\text{OLM}(s)}{1+H_\text{OLM}(s)}$$

先頭の括弧が2量の差。ゲイン整合条件 $K_\text{FF}=\dfrac{kN_1 K_\text{PDM}}{M_1 K_\text{PD1}}$ を満たすと括弧＝0 → 外部VCO PN が抑圧される（厳密には PD のサンプリング sinc で完全0にはならず、$f_\text{REF}$ にノッチを持つ等価HPF特性になる：低域は完全キャンセル、高域はキャンセル経路が余計に減衰）。

外部PLL 等価基準換算PN → 出力（式6.9）：ゲイン整合時は

$$H_\text{EQUIV1,OUT}(s)=\frac{kN_1}{M_1}\cdot\frac{H_\text{OLM}(s)}{1+H_\text{OLM}(s)}$$

＝キャンセル無し版と同じ、ただし外部PLLからのLPFが無い。→ キャンセルは「フィードフォワードのタップ点（PD出力）より後」のブロック（外部VCO・外部LF）にだけ効き、それより前（PD自体・基準・分周器）には効かない。

6.3.3 ゲイン誤差の影響

  • Fig. 6.7：完全整合なら理想HPF（DC完全抑圧、カットオフ ≈40MHz ＝ $f_\text{REF}/2$、$f_\text{REF}=80$MHz）。ゲイン誤差10%だと低域が $20\log(0.1)=-20$ dB で飽和。ただしフィードフォワードなので大きなゲイン誤差でも peaking は出ない。
  • Fig. 6.8：ゲイン誤差 <20% なら出力PNへの影響は小。Fig. 6.10：±20% ゲイン誤差でジッタ劣化は約3%。設計目標は ±20%。

6.4 実装と測定（7GHz試作）

6.4.1 実装詳細（Fig. 6.11）

  • TSMC 65nm。外部PLL：type-II SPDベース（LFに工夫）。メイン・外部の LC-VCO は8の字インダクタで磁気結合低減。外部PLL用にリングVCOも実装（1段目のPN寄与が大きい場合でも効くことを実証するため）。
  • SPD出力 → ゲイン段（2段OTA＋抵抗帰還で正確なゲイン）→ 抵抗網でメインPLLのPD出力と加算。メインPLL：3次HM、type-I（XOR-PD＋2段RC LF、[53]類似）。XOR-PD前の ÷2 は MMD/HM出力の立ち上がりを立ち上がり＋立ち下がりに変換するため（XOR-PDは両エッジに反応）。
  • 外部帯域 ≈8MHz（$f_\text{REF}=80$MHz より十分狭くPVTでも安全）。メイン帯域 ≈3MHz（メインVCO PN・量子化ノイズ・等価基準換算PN のトレードオフ最適化）。
  • 周波数：$f_\text{OUT}$ 6.46–6.77GHz、外部PLL 4.16–4.32GHz → ÷2 → 2.08–2.16GHz、HM出力 180–300MHz。

この外部PLLアーキテクチャを選んだ理由

  • SPD出力をVCOに直結しない（kick-back でキャンセルに悪影響のリスク）。
  • ゲイン段入力のオフセットを避けたい（出力飽和でメインPLLが動かなくなる）→ 外部LFに大きなDCゲイン（積分器）を持たせ、ロック後のSPD出力DC電圧を外部基準電圧で設定、同じ基準電圧をゲイン段のACグランドにも使う → ゲイン段入力が小さく保たれる。
  • 典型的な gm セル型 type-II（Fig. 6.12）は開ループ $g_m$ に強く依存しPVTに弱い。提案LF（Fig. 6.13a）は閉ループアンプ：$H_\text{LF,prop}(s)=\dfrac{A}{1+A}\dfrac{1+sRC}{\frac{1}{1+A}+sRC}\approx\dfrac{1+sRC}{sRC}$（$A\gg1$）→ DCに零点＋極、受動素子だけで特性が決まる。従来 $H_\text{LF,conv}(s)=\dfrac{1+sRC}{sC/G_m}$ は DCゲインが $G_m$ 依存。提案は OTA の低出力インピーダンスが有利（gm セルは高出力インピーダンスが要り低電源で困難）＝スケーリングフレンドリー。

ゲイン変動への対処

整合条件 $\dfrac{kK_\text{PDM}}{M_1}=\dfrac{K_\text{FF}K_\text{PD1}}{N_1}$。$k, M_1, N_1$ は離散値で不変。$K_\text{PDM}=V_\text{DD}/2\pi$（XOR-PD、LDOで安定）。$K_\text{FF}$ は抵抗比なのでコーナーで ±0.7%。問題は $K_\text{PD1}$（SPDゲイン）：単純なインバータ＋容量負荷だと PVT で 50%超変動。→ current-starved インバータ＋SC（スイッチトキャパシタ）ベースのバイアス発生器 [80] をスロープ発生器に。$I_\text{tail}\propto C_\text{SCB}$（$V_\text{BandGap}$ は BGR で安定）、スロープ $\propto I_\text{tail}/C_1$ → 絶対容量でなく $C_1/C_\text{SCB}$ の比に依存＝PVTに強い。[80] は ±2%、本設計は非理想設計で ±16%（インバータのトランジスタがテール電流源に対し小さすぎた）。それでも合計ゲイン誤差 ±17% で目標 ±20% 内。Fig. 6.15：従来テール電流バイアス ±30% vs SC ベース ±16%。

デジタル実装（TDC/BBPD＋デジタルループ）ならフィードフォワードゲイン変動を気にせず加算も容易だが、デジタルPLL固有の課題（PD量子化ノイズ、リミットサイクル）もある。今回はコンセプト実証なのでアナログ寄りの安全策をとった。

6.5 章のまとめ

高速遅延線を使わない電圧領域フィードフォワード雑音キャンセルをカスケードPLLに提案。外部VCOのPNオーバーヘッド（HMベース／カスケードPLL共通のボトルネック）を大幅緩和。信号経路とキャンセル経路のゲイン誤差、SPDゲインのPVT対策（SCベースバイアス）も扱い、HMベースPLLのキャリブレーション不要という性質を保ったまま SOTA 級のジッタ-電力・スパー性能を達成。

💬 第6章 Q&A

1フィードバック型VCDLの $H_\text{PLL,OUT}=\frac{1}{1+K_\text{PD}K_\text{VCDL}H_\text{LF}}$ と、フィードフォワード型の $1-K_\text{PD}K_\text{VCDL}$。なぜ後者は「0」になり得る？

フィードバック型は誤差を「制御ループで追い込む」ので伝達関数が $1/(1+\text{ループ利得})$ の形＝有限。フィードフォワード型は「打ち消すべき量を予測して直接引き算」するので、予測（$K_\text{PD}K_\text{VCDL}$）が実際（1）と完全一致すれば差がゼロになる。ただし実際は PD のサンプリング（sinc、$f_\text{REF}$ にノッチ）で高域のキャンセル経路が減衰するので完全0にはならず、等価的にHPFになる。

2提案は「PD出力をそのまま足す」だけ。なぜ高速VCDLが要らないの？

カスケードPLLでは外部PLLの出力PN成分が2段目PDの出力に現れ、そこでは信号がDCへダウンコンバートされて低周波になっている。低周波の電圧信号なら普通のアンプ＋抵抗加算で処理できる。single-loop PLLの出力は最終の高周波信号（時間領域）なので、キャンセルには時間軸をいじるVCDL（時間領域処理）が必要になる。カスケード構成という土俵だからこそ電圧領域でできる。

3ゲイン整合条件 $K_\text{FF}=\frac{kN_1 K_\text{PDM}}{M_1 K_\text{PD1}}$ のうち、実際に暴れるのはどれ？対策は？

$k, M_1, N_1$ は離散値で不変。$K_\text{PDM}=V_\text{DD}/2\pi$（XOR-PD、LDOで安定）。$K_\text{FF}$ は抵抗比で ±0.7%。$K_\text{PD1}$（外部PLLのSPDゲイン）が単純構成だと50%超変動する。対策：current-starved インバータ＋SCベースバイアス発生器 [80]。テール電流 $I_\text{tail}\propto C_\text{SCB}$、スロープ $\propto I_\text{tail}/C_1$ → 容量の絶対値でなく $C_1/C_\text{SCB}$ の比に依存＝PVTに強い。本作は ±16%（設計非理想）、合計 ±17% で目標 ±20% 内。

4「キャンセルはタップ点より後のブロックにだけ効く」とは？

フィードフォワード信号を取るのは外部PLLのPD出力。その点より後のブロック（外部VCO、外部LF）のノイズは、PD出力に予測情報として現れるので打ち消せる。より前のブロック（PD自体、基準、分周器）のノイズは打ち消せない（式6.10で外部PLLからのLPFが消えるだけで、等価基準換算PN はそのまま残る）。だから外部PLLのPD／基準は依然として低ノイズに作る必要がある。

5ゲイン誤差があると peaking しない？

しない。フィードフォワードでループを作らないので安定性の問題が無い。ゲイン誤差があると低域のキャンセルが浅くなる（10%誤差→−20dBで飽和）だけで、余計な山は出ない。±20%誤差でもジッタ劣化は約3%。だから広帯域キャンセルを、動作不良のリスクなしに設計できる。

6外部PLLにわざわざリングVCOも実装したのはなぜ？

「1段目（外部PLL）のPN寄与が非常に大きい最悪ケースでもキャンセルが効く」ことを示すため。実際 Fig. 6.20 で、外部リングVCO（フリーラン783fs級）でもキャンセルONで127fs＝外部LC-VCOの場合(106fs)とほぼ同等まで持っていけた。

✅ 第6章 理解度確認問題

Q6-1. Dual-Feedback で「量子化ノイズは減ったが代わりに増えたもの」は何か。この章の目標は？

外部（補助）PLLのVCO 1個ぶんの位相雑音。ノイズ増幅回避の代償として、HM用LOを作る外部PLLが要り、そのVCO PN が乗る。目標は、この余分なVCOのPNオーバーヘッドを無視できるレベルまで消すこと。

Q6-2. 広帯域外部PLLでVCO PN を抑える方法の限界を3つ挙げよ。

①$f_\text{BW}\le0.5f_\text{REF}$ の壁＋高周波基準はコスト高。②$f_\text{BW}/f_\text{REF}$ が大きいとプロセス変動で peaking / 不安定。③広帯域は type-I になり、DCに1極だけでVCO低周波PN抑圧が非効率（HPF 20dB/dec）。積分パス追加も比例パスよりゲインを下げる必要があり限定的。加えてHMの周波数プラン（$f_\text{HM}$ が広範囲をカバー）も難しくなる。

Q6-3. 提案の核心を1文で。なぜカスケードPLLだからこそできるのか。

外部PLLのPD出力（打ち消すべき外部VCO PN の情報を含む低周波信号）を、メインPLLのPD出力に電圧のまま足し込んで外部VCO PN を打ち消す。カスケードPLLでは外部PLLの出力PNが2段目PD出力でDC付近＝低周波になるので電圧領域処理でき、high-speed VCDL が要らない。

Q6-4. $H_\text{VCO1,OUT}(s)$ の先頭の括弧を書き、ゼロになる条件を示せ。厳密にゼロにならない理由は？

$\left(\dfrac{kK_\text{PDM}}{M_1}-\dfrac{K_\text{FF}K_\text{PD1}}{N_1}\right)$。$K_\text{FF}=\dfrac{kN_1 K_\text{PDM}}{M_1 K_\text{PD1}}$ で括弧＝0。厳密には、PDが立ち上がりエッジでのみサンプリングするため PDゲインに sinc（$f_\text{REF}$ にノッチ）が掛かり、キャンセル経路が高域で余計に減衰する。結果、低域は完全キャンセル・高域はキャンセルが浅い＝等価的にHPF特性になる。

Q6-5. 提案LF（閉ループアンプ）が従来 gm セル型より PVT に強い理由を式で。

提案：$H_\text{LF,prop}(s)\approx\dfrac{1+sRC}{sRC}$（$A\gg1$）＝受動素子 $R,C$ だけで決まる。従来：$H_\text{LF,conv}(s)=\dfrac{1+sRC}{sC/G_m}$ ＝ DCゲインが $G_m$（PVT変動大）に依存。また提案は OTA の低出力インピーダンスが理想に近く、gm セルは高出力インピーダンスが要る（低電源で困難）ので、提案のほうがスケーリングフレンドリー。

Q6-6. Fig. 6.19 と Fig. 6.20 の結果を比較して言えることは？

外部LC-VCO：キャンセル OFF 125fs → ON 106fs。外部リングVCO：OFF 410fs → ON 127fs。外部VCOのPNが桁違いに悪いリングVCOでも、キャンセルONにすればLC-VCOの場合とほぼ同等のジッタまで持っていける ＝ フィードフォワード雑音キャンセルは1段目のPN寄与が支配的な状況で特に強力。

7.2 将来展望（＝修論・後続研究のネタ）

① mm-wave 周波数シンセ ― Dual-Feed-Forward アーキテクチャ

  • Dual-Feedback と似た量子化ノイズ抑圧を持つ別構成 [69,88]（Fig. 7.1）。メインPLLの帰還経路に分周器が不要 → mm-wave に有利（高周波分周器は難しい。ILFD は面積大・ロックレンジ狭・分周比のプログラマビリティ低、prescaler カスケードで悪化）。HM は出力を既に基準周波数までダウンコンバートしているのでLCタンクが要らず、ロックレンジ・可変性を損なわない。
  • 使い分け：メインPLL出力の方が高周波なら Dual-Feedback が有利、外部PLLの方が高周波なら Dual-Feed-Forward が有利。

② スケーリングフレンドリーなHM ― N-path S/H

  • HM のpost-S/H LPF がボトルネック（LO周波数付近のトーンを扱うので高次・狭帯域・大面積）。pre-S/H LPF は高次高調波を落とすだけなので低次・広帯域・小面積で済む。
  • 無線受信機の harmonic rejection で使われる N-path サンプリング [67,89–92] ＋ 大幅簡略化した LPF で置き換える案（Fig. 7.2）。N相クロックは外部PLLをN段リングVCOにして生成、メインPLLもN段リングVCOにして入力位相をシフト（S/H後の位相シフトより簡単）。HMベース帰還は無線受信機の信号経路に似ているので、無線回路の工夫が参考になる。

③ 応用 ― マルチチャネル

  • HMベースPLLは「カスケードPLL」で、しかも 1段目 integer-N ／ 2段目 fractional-N（[93,75,94,95] とは逆）。マルチチャネル有線トランシーバや無線フェーズドアレイでは、チャネルごとに個別（個別可変）クロックが要る。
  • Fig. 7.3：全チャネルで1つの外部PLLを共有。外部PLLに大電力を注いでもチャネル数で割れば1chあたりは軽い。2段目が fractional-N なので各chの周波数を細かく個別調整できる。

④ 他手法との組み合わせ ― Dual-Feedback ＋ DTC

  • Dual-Feedback の中に DTC を入れる（Fig. 7.4）。DTC の熱雑音・量子化ノイズも増幅回避で乗らない → Fig. 7.5：Dual-Feedback＋DTC は Dual-Feedback 単体・DTC単体より良いジッタ-電力。残るオーバーヘッドは外部VCO（6章のFF雑音キャンセルや広帯域外部PLLで抑えられる）。
  • 難点：キャリブレーション不要という利点を失う（ただし非線形起因スパーは増幅されないので線形性キャリブレーションは省ける可能性）。

✅ 第7章 理解度確認問題

Q7-1. Dual-Feed-Forward が mm-wave に向く理由は？

メインPLLの帰還経路に分周器が要らないから。mm-wave では高周波分周器（デジタルMMDは動作困難、ILFDは面積大・ロックレンジ狭・分周比可変性低）が大問題。HM はすでに出力を基準周波数までダウンコンバートしているのでLCタンクを介した発振が不要で、ロックレンジ・可変性を損なわない。

Q7-2. なぜ post-S/H LPF がHMの「スケーリングの足かせ」なのか。N-path S/H でどう解決する？

post-S/H LPF は LO 周波数付近のトーン（Type-A）を扱うので高次・狭帯域＝受動素子が多く大面積。pre-S/H LPF は高次高調波を落とすだけなので軽い。N-path サンプリング（多相クロックで harmonic rejection）を使えば不要トーン自体を打ち消せ、post-LPF を大幅に簡略化できる。多相クロックは外部・メインをN段リングVCOにして生成。

Q7-3. Dual-Feedback＋DTC が単体より良くなる理由と、その代償は？

DTC で量子化ノイズを消し、DTC自身の熱雑音・量子化ノイズも Dual-Feedback の増幅回避で乗らない → 両者の弱点を相殺しジッタ-電力が改善。代償はキャリブレーション不要という利点を失うこと（ただし非線形起因スパーが増幅されないので線形性キャリブレーションは省ける可能性がある）。

🏁 総合確認問題（章をまたぐ理解のチェック）

✅ 総合問題

F-1. この論文の「1本の筋」を、敵・武器・武器の副作用・副作用への対策の4段で述べよ。

敵：Fractional-N PLL の DSM量子化ノイズ／フラクショナルスパー。分周器帰還（β=1/N）でこれが N 倍増幅される。
武器：帰還を「割り算」から「高調波ミキサによる引き算」へ。β=1 になりノイズが増幅されない（3章 Dual-Feedback）。
副作用：①S/H由来のオフセットスパー（4章）②ノイズシェーピング周波数が頭打ち＝リングVCOで不足（5章）③HM用LOを作る外部VCOのオーバーヘッド（6章）。
対策：①pre/post LPF の設計指針、②分割帰還分周＋PDLPF を Dual-Feedback に内蔵、③電圧領域フィードフォワード雑音キャンセル。

F-2. 「PNではなくジッタで考える」理由を、÷N と ×N を通した思考実験で説明せよ。

出力を ÷N すると PN は 1/N（パワーで 1/N²）に減るが周期は N 倍。位相は「1周期＝2π」の相対量なので、PN の 1/N 減と周期 N 倍が相殺し、時間軸の揺らぎ＝積分ジッタは不変。その後 ×N（理想逓倍でも）すると PN が N² 倍に戻り元通り＝÷N ×N の操作は無意味。だから PN の絶対値ではなく $\sigma\propto\sqrt{\text{積分PN}}/f_\text{OUT}$ で決まる積分ジッタで比較する。

F-3. Triple-Loop・Dual-Feedback・Dual-Feedback+PDLPF の3つで、量子化ノイズがどう扱われるか比較せよ。

Triple-Loop：補助 fractional-N PLL で $N_2+\alpha$ 倍増幅 → $\div M_2$ で減衰 → HMベースメインで再増幅なし。正味 ≈ $M_2$ 倍改善。LPF2段。
Dual-Feedback：メインPLL入力で発生 → 一度も増幅されず出力へ。$N_2+\alpha-1$ 倍改善。LPF1段。ただしノイズシェーピング周波数は $f_\text{HM}$ で頭打ち。
Dual-Feedback+PDLPF：さらに分割帰還分周でシェーピング周波数を $N_2$ 倍に上げ、Nested PLL（PDLPF）で追加LPF。$H_\text{DSM,OUT}$ は「Nested＋メインの2段カスケードLPF」×ゲイン $1/N_2$。従来単一ループ [79] 比で $N_1N_2$ 倍改善。

F-4. HMを「単純ミキサ」でなく「高調波ミキサ」にし、さらに「LO前に分周器」を足す。それぞれ何のため？

単純ミキサ：帰還ゲイン β=1 でノイズ増幅を回避。だが $f_\text{REF}\ll f_\text{LO}$ が要る（4章）ので $f_\text{LO}\approx f_\text{OUT}$ → 周波数引き込み。
高調波ミキサ（$f_\text{HM}=f_\text{OUT}-k f_\text{LO}$）：$f_\text{OUT}$ と $f_\text{LO}$ を離して引き込みを緩和。だが $f_\text{OUT}\approx k f_\text{LO}$ で LO の $k$ 次高調波による引き込みが残る。
LO前に $k$ と互いに素な分周比の分周器：高調波成分が帰還経路で重なりにくくなり引き込みをさらに抑える。

F-5. 4章のオフセットスパーと、3章で測定されたフラクショナルスパーは別物か？両方 −65dBc 付近だが。

別物。フラクショナルスパー（2〜3章）は DSM の周期性＋ループ非線形（CPミスマッチ等）のノイズフォールディングで $\alpha f_\text{DSM}$ に出る。増幅回避で $N_2+\alpha-1$ 倍抑圧される。オフセットスパー（4章）は HM の S/H 動作そのものが生む Type-A/Type-B トーンで、$\Delta f=|f_\text{SH}-l f_\text{HM}|$ に出て、pre/post LPF で抑える。前者は「分周をやめた」ことの残り、後者は「HMを使った」ことの副作用。

F-6. 3章（LC-VCO）では Dual-Feedback が DTC と同等〜勝ち、5章（リングVCO）では負ける。この違いの本質は？

リングVCOはPNが悪く最適ループ帯域が広くなる。Dual-Feedback の残留ノイズは整形量子化ノイズ（$f$ とともに立ち上がる）で帯域を広げると寄与が増える。DTCベースの残留ノイズは平坦な白色ノイズで帯域幅の影響を受けにくい。だから広帯域が要るリングVCOでは DTC が有利、狭帯域で済むLC-VCOでは Dual-Feedback が有利。

F-7. 6章のFF雑音キャンセルが「single-loop PLLではできず、カスケードPLLならできる」理由は？

キャンセルには「打ち消すべき位相誤差の情報」を取り出す点が要る。カスケードPLLでは外部PLLの出力PNが2段目PD出力でDC付近＝低周波の電圧信号になるので、普通のアンプ＋抵抗加算で処理できる。single-loop PLL の出力は最終の高周波信号で、キャンセルには時間軸をいじる＝高速VCDL（時間領域処理）が要る。VCDL は高速動作＋広い遅延レンジで低PN化が難しい。

F-8. なぜHMベースPLLは「キャリブレーション不要」で、それがなぜ重要なのか。

HMベースは線形なループ特性そのもの（DCゲインを下げる）で量子化ノイズを抑える。DTCベースのように「キャンセル信号のゲイン・線形性を実信号に合わせ込む」必要が無いので LMS/LUT キャリブレーションが不要。重要な理由：キャリブレーション収束は数十µs〜最悪ms、しかも周波数切替のたびに必要。周波数ホッピングやデューティサイクル無線ではこれが致命的（点灯時間が延び省電力効果が消える）。HMベースはロック時間＝ループ過渡だけ（数百ns〜µs）。

F-9. 各試作チップの狙いと看板数値を対応づけよ（3章・5章・6章）。

3章：3.5GHz、LC-VCO、65nm。狙い＝Dual-Feedback が量子化ノイズ増幅を回避できることの実証（メインPLLのみ、LOは外部）。フラクショナルスパー −65 dBc、量子化ノイズ寄与 ≈33 dB改善。
5章：3GHz、3つとも差動リングVCO、65nm、コア0.112mm²。狙い＝リングVCOでの量子化ノイズ抑圧。FoM −229.4 dB、ロック460 ns、フラクショナルスパー −49 dBc、Nested PLL 電力5.7%。
6章：7GHz（実測は÷4出力）、LC/リング両方の外部VCO、65nm。狙い＝FF雑音キャンセルで外部VCOオーバーヘッド削減。FoM −248.5 dB、フラクショナル/基準スパー −63 / −77 dBc、キャンセルON/OFFで 106/125fs。
